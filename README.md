# Benchmark-Sintetico

Este repositorio contiene el código fuente de un Benchmark Sintético desarrollado en lenguaje ensamblador de 16 bits para la arquitectura Intel 8086/8088.

El programa ejecuta una carga de trabajo constante y predecible para comparar el rendimiento de diferentes computadores o configuraciones emuladas, calculando su potencia de procesamiento en MIPS (Millones de Instrucciones Por Segundo).

El programa unifica en un solo ejecutable (.EXE) las siguientes fases críticas:
- Temporización de Alta Precisión.
- Carga de Trabajo Sintética (Estrés Gráfico).
- Restauración y Salida Segura.
